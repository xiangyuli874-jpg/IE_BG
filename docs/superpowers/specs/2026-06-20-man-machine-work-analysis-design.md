# 人机作业分析 Excel VBA 自动化模板设计

## 1. 目标

开发一套适用于制造现场的人机作业分析 Excel VBA 模板。模板不做成独立软件或工具箱，而是在 Excel 内完成资料录入、资源分配、自动排程、人机作业图、负荷分析和改善前后对比。

模板支持：

- 最多 5 名人员。
- 最多 10 台设备。
- 每台设备最多 20 个作业步骤。
- 各设备可使用不同工序、工时和生产顺序。
- 人员技能权限、设备间移动时间和人工锁定约束。
- 四种优化目标和可追溯的 VBA 启发式排程。

最终文件使用宏启用格式 `.xlsm`，作为现有工时模板之外的独立模板交付，不覆盖已有文件。

## 2. 案例与功能参考

设计参考了以下三个案例视频：

- `https://www.bilibili.com/video/BV1CtVM6AEaC/`
- `https://www.bilibili.com/video/BV19xVE65EZL/`
- `https://www.bilibili.com/video/BV1Sb7r6LEq6/`

前两个视频的案例为 1 人操作 3 台相同设备：

- 人员上料：5 秒。
- 设备自动运行：20 秒。
- 人员翻面：6 秒。
- 设备自动运行：15 秒。
- 人员下料：5 秒。

错峰排列后，一个稳定循环为 56 秒，完成 3 件，平均节拍为 `56 ÷ 3 = 18.67 秒/件`。

第三个视频值得借鉴的功能包括：

- 每台设备独立维护工序和工时。
- 区分循环生产关系与有先后顺序的设备关系。
- 一键生成连续生产排程。
- 输出循环周期、节拍和产能。
- 同时展示人员与设备时间轴。
- 提供全部、仅人员、仅设备的明细视图。
- 输出各作业的开始时间、结束时间、持续时间和执行资源。

本模板在这些能力上增加多人员技能、移动时间矩阵、手动锁定、四种优化目标以及改善前后对比。

## 3. 工作簿结构

工作簿控制为 5 个工作表，用户主要在前两个工作表集中录入。

### 3.1 基础设置

同一页面划分为四个有独立表头的区域：

1. 分析参数
   - 方案名称。
   - 人员数量。
   - 设备数量。
   - 计划分析循环数。
   - 优化目标。
   - 启发式搜索次数或时间上限。
   - 综合优化权重。

2. 人员与技能
   - 人员编号。
   - 人员名称。
   - 可操作设备。
   - 可执行步骤或技能类别。
   - 是否启用。

3. 设备资料与生产关系
   - 设备编号。
   - 设备名称。
   - 产品或工件名称。
   - 生产关系类型：独立循环或有先后顺序。
   - 前置设备或前置工件关系。
   - 是否启用。

4. 移动时间矩阵
   - 行列均为设备或起始位置。
   - 单元格填写人员从一个位置移动至另一个位置所需秒数。
   - 对角线默认为 0。

### 3.2 作业步骤

使用一张结构化表格集中录入全部设备步骤，每行代表一个作业步骤：

- 设备编号。
- 步骤序号。
- 步骤名称。
- 步骤类型。
- 工时（秒）。
- 前置步骤。
- 可执行人员或技能要求。
- 锁定人员。
- 锁定开始时间。
- 是否允许等待。
- 备注。

步骤类型包括：

- 人工作业：占用人员，不占用设备自动运行资源。
- 设备自动运行：占用设备，不占用人员。
- 人机协同：同时占用人员与设备。
- 等待：用于明确表达工艺规定的等待；排程引擎产生的资源等待另行计算。

### 3.3 自动排程

该页为运算控制台和排程明细页，包括：

- 数据检查结果。
- 当前优化目标与权重。
- 当前方案评分。
- 冲突与无解原因。
- 排程明细表。
- 操作按钮。

排程明细至少包含：

- 任务编号。
- 循环编号。
- 设备。
- 步骤。
- 执行人员。
- 开始时间。
- 结束时间。
- 持续时间。
- 任务类型。
- 前置任务。
- 是否锁定。
- 等待原因。

### 3.4 人机作业图

自动生成以时间为横轴的甘特式人机作业图：

- 上部为人员时间轴。
- 下部为设备时间轴。
- 支持全部、仅人员、仅设备三种视图。
- 按实际人员数、设备数和循环周期自动调整范围。

颜色约定：

- 人工作业：蓝色。
- 设备自动运行：绿色。
- 人机协同：橙色。
- 人员移动：紫色。
- 资源等待：红色或红色斜纹。
- 空闲：浅灰色。

### 3.5 改善对比报告

对“改善前”和“改善后”两个已保存方案进行对比，自动输出：

- 循环周期。
- 平均节拍。
- 小时产能。
- 各人员负荷率。
- 人员作业、移动和空闲时间。
- 各设备利用率。
- 设备自动运行、等待人员和空闲时间。
- 瓶颈人员。
- 瓶颈设备。
- 最长等待步骤。
- 指标差值。
- 改善百分比。
- 基于明确规则生成的改善建议。

## 4. 数据输入与视觉规范

- 黄色单元格：必填输入。
- 浅蓝色单元格：选填或约束输入。
- 灰色单元格：公式、VBA 输出或不可编辑区域。
- 下拉列表用于人员、设备、步骤类型、生产关系和优化目标。
- 关键输入区域使用 Excel 表格，新增行时延续格式与验证。
- 工作簿字体统一使用微软雅黑。
- 时间统一以秒作为底层计算单位，结果按需要显示为秒或时分秒。

## 5. 数据校验

运行排程前必须检查：

- 人员数与设备数是否超过上限。
- 已启用设备是否至少有一个步骤。
- 工时是否为正数。
- 同一设备步骤序号是否重复或缺失。
- 前置步骤是否存在。
- 是否存在循环依赖。
- 人工或人机协同步骤是否至少有一名合格人员。
- 锁定人员是否具备对应技能。
- 锁定开始时间是否与前置约束冲突。
- 移动时间矩阵是否完整且为非负数。
- 有先后顺序的设备关系是否形成循环。

发现错误时，自动排程停止，并在控制台标记具体工作表、表格行和错误原因。

## 6. 排程约束

排程引擎遵守以下硬约束：

- 同一人员不能同时执行两个任务。
- 同一设备不能同时执行两个占用设备的任务。
- 同一设备的步骤按定义顺序执行。
- 前置任务完成后，后续任务才能开始。
- 人员从上一个位置到下一设备前必须完成移动。
- 人机协同步骤要求人员与设备在同一时段同时可用。
- 锁定人员、锁定开始时间和锁定顺序在重新优化时保持不变。
- 有先后生产关系的设备或工件必须遵守指定关系。

## 7. 自动排程与优化

### 7.1 初始方案

VBA 先使用可解释的规则生成可行初始方案：

1. 建立任务与前置关系。
2. 找出当前可执行任务。
3. 计算设备、人员和移动的最早可用时间。
4. 按当前目标的优先规则选择任务与人员。
5. 插入必要移动和资源等待。
6. 重复直至计划循环全部排完。

### 7.2 启发式优化

初始方案生成后，通过多轮邻域搜索寻找更优方案。允许的调整包括：

- 改变同一优先级任务的执行顺序。
- 在合格人员之间重新分配任务。
- 调整设备首次启动的错峰时间。
- 调整非锁定任务的局部顺序。

每轮候选方案必须先通过硬约束检查，再根据目标函数评分。只有评分改善时才替换当前最佳方案，并保留随机种子、迭代次数和评分明细，确保结果可追溯。

### 7.3 四种优化目标

1. 最高产能
   - 优先最小化稳定循环周期。
   - 次要减少总等待和移动。

2. 人员均衡
   - 优先降低人员负荷率极差或标准差。
   - 对超负荷人员增加惩罚。
   - 同时设置循环周期恶化上限，避免用显著降产换取表面均衡。

3. 设备少等待
   - 优先减少设备等待人员的总时长和最大等待时长。
   - 次要控制循环周期。

4. 综合优化
   - 按用户权重综合计算循环周期、人员不均衡、设备等待和移动时间。
   - 默认权重以产能为主，但允许用户修改。

评分细节在`自动排程`页显示，避免黑箱结论。

## 8. 手动调整与方案管理

用户可以锁定：

- 指定人员。
- 指定开始时间。
- 指定任务顺序。

重新优化时仅调整未锁定任务。若锁定条件导致无解，系统列出具体冲突，不静默修改锁定内容。

方案管理包括：

- 生成初始方案。
- 优化排程。
- 锁定或解锁任务。
- 撤回至上一个方案。
- 保存为改善前方案。
- 保存为改善后方案。
- 刷新对比报告。

每次优化前保存当前方案快照，至少支持一次撤回。

## 9. 指标定义

- 循环周期：稳定循环边界之间的时间。
- 平均节拍：循环周期除以该循环内合格产出数量。
- 小时产能：`3600 ÷ 平均节拍`。
- 人员负荷率：分析周期内人员作业时间除以可用时间。
- 人员移动占比：移动时间除以可用时间。
- 人员空闲率：空闲时间除以可用时间。
- 设备利用率：设备有效作业时间除以分析周期。
- 设备等待人员时间：设备已具备工艺条件但因人员不可用造成的等待。
- 瓶颈人员：负荷率最高或导致最多资源等待的人员。
- 瓶颈设备：周期贡献、利用率或等待影响最大的设备。

多人、多设备情况下，报告同时展示平均值和逐资源明细，避免平均数掩盖瓶颈。

## 10. VBA 模块边界

VBA 代码按职责拆分：

- 数据读取与模型转换模块。
- 数据校验模块。
- 初始排程模块。
- 启发式优化与评分模块。
- 锁定、撤回和方案存档模块。
- 工作表输出与图表刷新模块。

模块之间通过明确的数据结构传递任务、资源、约束和方案结果，避免直接在核心算法中频繁读写单元格。

## 11. 内置示例

模板首次打开时预置视频中的 1 人 3 机示例：

- 3 台相同设备。
- 上料 5 秒。
- 自动运行 20 秒。
- 翻面 6 秒。
- 自动运行 15 秒。
- 下料 5 秒。

示例用于验证模板可以生成约 56 秒完成 3 件、平均约 18.67 秒/件的稳定错峰方案。由于启发式搜索可能存在等价排程，验收重点为约束正确、循环边界正确和指标计算一致。

## 12. 验证与验收

至少覆盖以下场景：

1. 视频中的 1 人 3 机案例。
2. 不同设备具有不同步骤和工时。
3. 多人员具有不同技能权限。
4. 移动时间影响人员分配与排程。
5. 锁定人员或开始时间后重新优化。
6. 锁定条件导致无解时正确报告冲突。
7. 前置关系循环时阻止排程。
8. 四种优化目标产生可解释的评分差异。
9. 改善前后方案保存与对比。
10. 甘特图按实际资源和周期自动扩展。

完成标准：

- `.xlsm` 可正常打开且宏按钮可用。
- 所有输入区域、下拉验证和格式清晰。
- 关键公式与指标无错误。
- 1 人 3 机基准案例结果正确。
- 排程不存在人员、设备或前置关系冲突。
- 无解案例提供明确原因。
- 人机作业图和改善报告可读且无明显裁切。

## 13. 不在本次范围

- 不开发独立桌面软件或在线工具。
- 不接入外部数据库、MES 或 ERP。
- 不依赖 Excel Solver 加载项。
- 不实现无限人数、无限设备或无限步骤。
- 不承诺数学意义上的全局最优解；目标是在受控时间内得到可行、可解释且通常优于初始方案的结果。
